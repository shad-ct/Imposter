# App Icon Setup

## Instructions

1. **Place your logo here** as `logo.png` (recommended size: 1024x1024 or larger)
   - The logo should be a PNG file with transparency if needed
   - For best results, use a square image

2. **Run the icon generator:**
   ```bash
   flutter pub get
   flutter pub run flutter_launcher_icons
   ```

3. **Done!** All icon sizes will be automatically generated for:
   - Android (all densities)
   - iOS (all sizes)
   - Web
   - Windows
   - macOS

## Current Configuration
- Image path: `assets/icon/logo.png`
- Android adaptive icon background: Black (#000000)
- Platforms: Android, iOS, Web, Windows, macOS
